# VoiceTool v1.3.0 — 高機能AI音声合成・編集スタジオ

VoiceTool は、最新の AI 音声合成技術と直感的なタイムライン編集を統合した、次世代のデスクトップ音声制作ツールです。
v1.3.0 では、「AI 文脈解析」による自動感情アノテーションを搭載。セリフを入力するだけで、AI が最適なトーンを瞬時にプリセットします。

---

## 🚀 VoiceTool で実現できること

### 1. 驚異の「ゼロショット」ボイスクローニング
わずか数秒〜数十秒の音声ファイルを読み込ませるだけで、その話者の特徴（声質、癖、イントネーション）を即座にコピーできます。事前の追加学習は一切不要です。

### 2. インテリジェントな感情表現（Emotion Engine）
4つの感情パラメータを直感的に操作することで、声に「深み」を与えられます。各感情は音声特性に動的に反映されます：
- **幸せ (Happy)**: ピッチが上がり、明るいトーンに。
- **楽しみ (Fun)**: 再生速度が上がり、弾むようなリズムに。
- **怒り (Angry)**: 声に力が入り、音量が増大。
- **悲しみ (Sad)**: 低いトーンで、ゆっくりとした落ち着いた声に。

### 3. モジュール式エンジン・アーキテクチャ [NEW]
- **マルチエンジン基盤**: エンジンが抽象化されており、XTTS v2 だけでなく、将来的に OpenAI TTS や RVC 等の異なる音声合成エンジンを「プラグイン」として統合可能。
- **デバッグ用 Mock エンジン**: AI モデルなしで動作確認が可能な軽量エンジンを搭載。開発者の利便性を大幅に向上。

### 4. 精密なマイクロ調整
セグメント（行）ごとに、プロレベルの音声加工パラメータを個別に設定可能です：
- **ピッチコントロール**: -12 〜 +12 半音（1オクターブ）の範囲で調整可能。
- **スピード調整**: 0.5倍速〜2.0倍速まで、音程を変えずに変更。
- **音量バランス**: -20dB 〜 +20dB で出力レベルを最適化。
- **ポーズ挿入**: セグメント間に 0.0〜3.0秒 の無音時間をミリ秒単位で設定。

### 5. 視覚的なタイムライン編集
- **リアルタイム波形表示**: 生成された音声のダイナミクスを視覚的に確認。
- **プロ仕様の描画エンジン**: C/Assembly (SIMD) による高速化エンジンを搭載。長尺音声でも遅延のない滑らかな操作感を実現。

### 6. スマートなプロジェクト & キャッシュ
- **.vproj 形式**: 編集内容、パラメータ、感情設定をすべて保存・復元。
- **高速プレビュー**: 同一条件の音声はキャッシュから即座に再生。試聴コストを大幅に削減します。
- **高品質エクスポート**: WAV だけでなく、高品質な MP3 形式での一括書き出しにも対応。

### 6. 高い安定性と環境適応力
- **ステレオ完全サポート**: モノラルだけでなくステレオ音声の編集・ポーズ挿入も安定して動作。
- **ユニバーサル起動**: Windows 環境において `python` または `py` ランチャーを自動検出し、環境を選ばず確実に起動。
- **自動セットアップ**: 初回起動時に FFmpeg などの必要なバイナリや AI モデルを全自動で構成。

## 🏎️ 極限のパフォーマンス & 拡張性
VoiceTool は、快適な操作感と将来性を両立させるために最先端のアーキテクチャを採用しています。
- **ストリーミング波形生成 [NEW]**: 生成の完了を待たず、AI の出力に合わせてリアルタイムに波形を表示。
- **ビジュアル・プロソディ編集 [NEW]**: タイムライン上でピッチ（抑揚）をペンで描くように直感操作可能。Rubberband エンジンとの高度な連携により、プロ品質の抑揚調整を実現。
- **SIMD 最適化**: AVX2/SSE2 命令セットを活用し、音声解析を数ミリ秒で完了。
- **商用レベルの堅牢性 [NEW]**:
    - **数値安全ガード**: 全てのネイティブ計算層に NaN/Inf チェックを導入。異常データによる「音の爆発」やフリーズを完璧に防止します。
    - **メモリ保護**: Python-C 間のバッファ受け渡しを厳格に管理（ascontiguousarray）し、メモリアクセス違反によるクラッシュを根絶しました。
    - **スレッドセーフ**: 音声生成中の急な中断やウィンドウ終了も安全にハンドリング。

## 🛠 セットアップ & 実行

### システム要件
- **OS**: Windows 10/11 (64bit)
- **CPU**: モダンなマルチコアプロセッサ
- **GPU (推奨)**: NVIDIA GPU (VRAM 4GB以上)
- **ディスク**: 約 5GB 以上の空き容量（AIモデル用）

### インストール方法
1. 本リポジトリをダウンロードまたは `git clone` します。
2. 必要なライブラリをインストールします：
   ```bash
   pip install -r requirements.txt
   ```
3. `run.bat` を実行して開始！
