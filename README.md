# VoiceTool — 高機能AI音声合成・編集スタジオ

VoiceTool は、最新の AI 音声合成技術と直感的なタイムライン編集を統合した、次世代のデスクトップ音声制作ツールです。1つの参照音声（Reference Audio）だけで声をクローニングし、感情豊かで精密に制御された音声を生成できます。

---

## 🚀 VoiceTool で実現できること

### 1. 驚異の「ゼロショット」ボイスクローニング
わずか数秒〜数十秒の音声ファイルを読み込ませるだけで、その話者の特徴（声質、癖、イントネーション）を即座にコピーできます。事前の追加学習は一切不要です。

### 2. インテリジェントな感情表現（Emotion Engine）
4つの感情パラメータを直感的に操作することで、声に「深み」を与えられます。各感情は音声特性に動的に反映されます：
- **幸せ (Happy)**: ピッチが上がり、明るいトーンに。
- **楽しみ (Fun)**: 再生速度が上がり、弾むようなリズムに。
- **怒り (Angry)**: 声に力が入り、音量が増大。
- **悲しみ (Sad)**: 低いトーンで、ゆっくりとした落ち着いた声に。

### 3. 精密なマイクロ調整
セグメント（行）ごとに、プロレベルの音声加工パラメータを個別に設定可能です：
- **ピッチコントロール**: -12 〜 +12 半音（1オクターブ）の範囲で調整可能。
- **スピード調整**: 0.5倍速〜2.0倍速まで、音程を変えずに変更。
- **音量バランス**: -20dB 〜 +20dB で出力レベルを最適化。
- **ポーズ挿入**: セグメント間に 0.0〜3.0秒 の無音時間をミリ秒単位で設定。

### 4. 視覚的なタイムライン編集
- **リアルタイム波形表示**: 生成された音声のダイナミクスを視覚的に確認。
- **再生カーソル**: 現在の再生位置をタイムライン上で追跡。
- **セグメント管理**: テキストの改行ごとに自動分割。特定の行だけを再生成することも可能です。

### 5. スマートなプロジェクト管理
- **.vproj 形式**: 編集中のテキスト、パラメータ、感情設定をすべて保存・復元。
- **音声キャッシュ**: パラメータが変わっていない音声はキャッシュから再利用。試聴の待ち時間を最小限に抑えます。
- **一括書き出し**: 全セグメントを結合し、WAV または MP3 形式でプロ品質の音声を出力。

### 6. ストレスフリーな自動セットアップ
- **依存関係の自動解決**: 初回起動時に FFmpeg や Rubberband、AI モデルをクラウドから自動セットアップ。
- **デバイス自動検出**: NVIDIA GPU (CUDA) を自動認識し、高速な音声生成を実現（CPUモードも完備）。

## 🛠 セットアップ & 実行

### システム要件
- **OS**: Windows 10/11 (64bit)
- **CPU**: モダンなマルチコアプロセッサ
- **GPU (推奨)**: NVIDIA GPU (VRAM 4GB以上)
- **ディスク**: 約 5GB 以上の空き容量（AIモデル用）

### インストール方法
1. 本リポジトリをダウンロードまたは `git clone` します。
2. 必要なライブラリをインストールします：
   ```bash
   pip install -r requirements.txt
   ```
3. `run.bat` を実行して開始！
