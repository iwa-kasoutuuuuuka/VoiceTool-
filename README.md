# VoiceTool

VoiceTool は、音声編集とAI音声合成（TTS）を統合したデスクトップツールです。
テキスト入力から瞬時に高品質な音声を生成し、イントネーションやスピードを自由に調整して、一つの音声ファイルとして書き出すことができます。

![Main Window](assets/screenshot.png) <!-- 実際には画像はありませんが、プレースホルダーとして -->

## 主な機能

- **高性能AI音声合成**: Coqui TTS (VITS等) を使用した自然な音声合成。
- **直感的なタイムライン編集**: 生成された音声をタイムライン上で視覚的に管理。
- **感情・パラメータ調整**: ピッチ、スピード、音量、ポーズの個別設定が可能。
- **自動依存関係セットアップ**: ffmpeg や必要なモデルを初回起動時に自動ダウンロード。
- **プロジェクト管理**: 編集内容を `.vproj` 形式で保存・再開。
- **一括書き出し**: 全セグメントを結合して WAV/MP3 でエクスポート。

## フォルダ構成

```text
VoiceTool/
├── src/                    # ソースコード
│   └── voicetool/          # メインパッケージ
├── tests/                  # 単体テスト
├── docs/                   # マニュアル・仕様書
├── VoiceTool.spec          # PyInstallerビルド設定
├── portable_spec_jp.md     # ポータブル版用日本語仕様書
├── requirements.txt        # 依存ライブラリ
└── run.bat                 # 起動用バッチファイル
```

## ポータブル版の作成と配布

### 自身でビルドする場合
以下のコマンドを実行して、`dist/VoiceTool` フォルダに実行ファイルを生成します。
```bash
python -m PyInstaller VoiceTool.spec --noconfirm
```

### 配布時の注意点（オフライン対応）
ビルドされた `dist/VoiceTool` フォルダを配布する際、以下の点に注意してください：

- **自動セットアップ**: 起動時に `bin/`（ffmpeg等）や `models/`（AIエンジン）が見つからない場合、ネットワーク経由で自動的にセットアップが開始されます。
- **完全オフライン配布**: 完全にオフラインの環境で動作させたい場合は、開発環境のカレントディレクトリにある `bin/` フォルダと `models/` フォルダを、そのまま `dist/VoiceTool/` 内にコピーして同梱してください。

## セットアップ

### システム要件
- Windows 10/11 (64bit)
- Python 3.10 以上
- NVIDIA GPU (推奨、CUDAが利用可能な場合高速に動作します)

### インストール方法

1. リポジトリをクローンまたはダウンロードします。
2. 依存パッケージをインストールします：
   ```bash
   pip install -r requirements.txt
   ```
3. `run.bat` を実行するか、以下のコマンドで起動します：
   ```bash
   python src/voicetool/main.py
   ```
