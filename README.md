# VoiceTool v1.3.0 — Production Stability Update 💎

VoiceTool は、最新の AI 音声合成技術と直感的なタイムライン編集を融合させた、プロフェッショナル向け音声制作スタジオです。
v1.3.0 では、極限のパフォーマンスを追求したネイティブエンジンの統合と、一切のフリーズを排除した非同期アーキテクチャへの刷新が行われました。

---

## ✨ v1.3.0 の主要アップデート

### 🚀 極限のパフォーマンス (Native Boost)
- **C/SIMD 高速化 DLL**: 独自開発のネイティブエンジンを搭載。波形描画や音声処理を C 言語レベルで最適化し、長尺の音声でもストレスのない操作感を実現しました。
- **ポータブル・ビルド環境**: システムにコンパイラがない環境でも、同梱の Zig コンパイラを使用してネイティブ DLL を生成可能な「セルフビルド機能」を実装。

### 🧵 快適な操作性 (Async Architecture)
- **フル・非同期処理**: モデルの読み込み、音声の連結、エクスポート、再生準備など、時間のかかる処理はすべてバックグラウンド（QThread等）に移行。
- **ノンストップ UI**: どんなに重い処理の裏側でも、編集作業を止める必要はありません。

### 🎨 卓越した視認性 (Modern Dark UI)
- **高コントラスト最適化**: 深い紺色を基調とした、目に優しく情報の読み取りやすいカラーパレットを採用。
- **スマート・ログパネル**: 処理の成功、開始、エラーを HTML 色分けでリアルタイムに通知。開発と運用の両面で高い情報視認性を提供します。

## 🛠 主要機能

### 1. 驚異の「ゼロショット」クローニング
数秒の音声があれば、その話者の特徴を即座に再現。追加学習は一切不要です。

### 2. AI 文章解析エンジン
テキストを入力するだけで、AI が文脈を読み取り、最適な感情、ピッチ、速度を自動的にアノテーションします。

### 3. 精密な抑揚（プロソディ）編集
タイムライン上でマウスを使って直接ピッチカーブを描くことが可能。Rubberband エンジンとの連携により、不自然な抑揚をプロレベルで調整できます。

## 🚀 クイックスタート

### システム要件
- **OS**: Windows 10/11 (64bit)
- **GPU**: NVIDIA GPU (VRAM 4GB以上推奨)

### 実行方法
1. **リポジトリの準備**:
   ```bash
   git clone https://github.com/iwa-kasoutuuuuuka/VoiceTool-
   cd VoiceTool-
   ```
2. **環境構築**:
   ```bash
   pip install -r requirements.txt
   ```
3. **ネイティブエンジンのビルド (推奨)**:
   `build_native_zig.bat` を実行してください。波形描画が劇的に高速化されます。
4. **起動**:
   `run.bat` を実行してください。
