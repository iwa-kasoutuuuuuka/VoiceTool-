# VoiceTool v1.3.0 ポータブル版 仕様書

## 1. 概要
VoiceTool は、AI 音声合成（XTTS v2）と高度な波形編集機能を統合したデスクトップアプリケーションです。
本ポータブル版は、インストール不要で解凍後すぐにプロフェッショナルな音声制作を開始できるよう最適化されています。

## 2. パッケージ構成
配布フォルダ内には以下の重要な資産が含まれています：
- `VoiceTool.exe`: アプリケーション本体（ビルド済みスタンドアロン実行ファイル）
- `_internal/`: アプリケーションの動作に必要な内部ライブラリ群
- `bin/`: 外部処理バイナリ（FFmpeg, Rubberband）
- `models/`: 音声合成用 AI モデル（初回起動時に自動ダウンロード）
- `tools/zig/`: ネイティブエンジン構築用ポータブルコンパイラ
- `projects/`: ユーザープロジェクトの保存先
- `run.bat`: 開発者向けソースコード起動用スクリプト

## 3. v1.3.0 の主要な改善点
- **超高速波形描画**: 独自ビルドされたネイティブ DLL により、長い音声ファイルの描画が瞬時に完了します。
- **ノンストップ操作**: モデルのロードや音声の書き出しをバックグラウンドで処理するため、作業中にアプリケーションが「応答なし」になることはありません。
- **高視認性 UI**: ダークモードに最適化された配色により、長時間の作業でも目が疲れにくく、ログの確認も容易です。

## 4. 高速化エンジンの管理
本パッケージにはビルド済みの高速化 DLL が同梱されていますが、自身の環境に合わせて再構築することも可能です。
1. `build_native_zig.bat` を実行します。
2. 同梱されたポータブルコンパイラ（Zig）が自動的に現在の PC に最適なバイナリを再生成します。
3. 完了後、アプリケーションを再起動すると「高速モード」が適用されます。

## 5. 基本的な使用フロー
1. **テキスト入力**: 左側のパネルにセリフを入力します。
2. **AI 解析**: 「✨ AI解析」ボタンを押すと、文脈に合わせて感情パラメータが自動設定されます。
3. **音声生成**: 生成ボタンを押します。ステータスバーで進捗を確認でき、生成中も他の編集が可能です。
4. **プレビューと調整**: タイムラインで波形を確認し、必要に応じてピッチや速度を微調整します。
5. **最終出力**: 書き出しメニューから WAV または MP3 形式で保存します。
